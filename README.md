## ⚡ Key Features

1. **Interactive 3D Three.js Engine (`three-scene.js`)**:
   - 2,200+ particle galaxy constellation reacting to cursor position and scroll depth.
   - Central geometric wireframe cyber core with a **3D Shape Switcher** (Torus Knot, Cyber Icosahedron, Quantum Sphere, Hypercube Cage).
   - Graceful Canvas 2D / WebGL native fallback for instant offline/low-bandwidth rendering.

2. **Web Audio API Sound Synthesizer (`sound-effects.js`)**:
   - Zero-dependency procedural audio synthesis generating futuristic UI micro-tones on hover, click, and geometry shifts without external audio files.

3. **Dynamic 3D Card Tilt & Glare Effects (`script.js` & `style.css`)**:
   - Realistic mathematical perspective tilt following mouse physics with dynamic specular glare.

4. **Live Interactive Python Terminal REPL**:
   - Simulated terminal supporting commands like `help`, `skills`, `chainscope`, `atm`, `awards`, `about`, `github`, and `clear`.

5. **ChainScope Blockchain Risk Tracing Showcase**:
   - Winner of **Best AI Project Award at DevHack 2026** (IIMT University, Meerut; 1,150+ competitors).
   - Deep architectural exploration modal displaying Neo4j multi-hop Cypher queries and Random Forest classifier heuristics.

6. **Curriculum Vitae Modal & Print Engine**:
   - Built-in CV modal with formatted print media stylesheet for instant PDF export or printing.

## 💻 How to Run Locally

Simply open `index.html` in any web browser, or run a local HTTP server:

```bash
# Python 3
python -m http.server 5173

# Node.js npx
npx serve .
```

Then visit [http://localhost:5173](http://localhost:5173) in your browser.
